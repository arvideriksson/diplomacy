# Map attribution

`classical.dsvg` is derived from the classical Diplomacy map by **Martin Asal**,
distributed under **CC-BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/),
via the [diplicity-react](https://github.com/johnpooch/diplicity-react) project's
layered "dSVG" form.

The map is organized into named SVG layers (`background`, `provinces`,
`named-coasts`, `unit-positions`, `province-names`, `borders`, `foreground`) and is
rendered at runtime by `src/lib/map/`.
